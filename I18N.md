# Flexxy Internationalization (English + Czech)

## Overview

UI copy can be shown in **English** or **Czech (Čeština)**. Users switch language from the header dropdown. Preference is stored in `localStorage.preferredLanguage`.

| Piece | Path |
|-------|------|
| Runtime | `frontend/js/i18n.js` |
| English source | `frontend/locales/source.en.json` |
| Czech | `frontend/locales/cs.json` |
| DeepL batch | `translate.py` |
| Extract markers | `scripts/extract-translations.js` |

## How it works

1. Mark HTML with `data-i18n="key.path"` (keep English text as fallback inside the tag).
2. Placeholders: `data-i18n-placeholder="key"`.
3. Page titles: `<title data-i18n-title="page.title">...</title>`.
4. Image alts: `data-i18n-alt="key"`.
5. Aria labels: `data-i18n-aria-label="key"`.
6. JS strings: `window.i18n.translate('key', 'English fallback')`.

After dynamic HTML inject (header/footer), call:

```js
window.i18n.refresh();
```

`ComponentLoader` does this automatically after header/footer load.

## Add or update strings

```bash
# 1. Add data-i18n markers in HTML (or i18n.translate in JS)
# 2. Harvest English keys
node scripts/extract-translations.js

# 3. Translate missing keys to Czech (venv once)
python3 -m venv .venv-translate
.venv-translate/bin/pip install deepl
.venv-translate/bin/python translate.py --lang cs
```

DeepL key: set `DEEPL_API_KEY` or use the default free-tier key in `translate.py`.

## Notes

- Job listings from the API stay in their original language (not UI chrome).
- Country flag buttons in the header are **location filters**, not language.
- Language control is the EN / Čeština `<select class="language-switcher">`.
